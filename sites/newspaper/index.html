One Customer, One Memory

Before the change, a customer who wrote on WhatsApp and then called the helpline was two strangers to the bot. Kumar architected a cross-channel identity-resolution and unified memory layer spanning WhatsApp, the website, Instagram, Messenger and voice.

Agentic bots now keep short-term and long-term memory across sessions. A context-injection layer feeds configurable windows of LLM-written session summaries into each prompt, so customers are not asked the same questions twice and every inference costs less.

At its centre is a multi-strategy identity resolver: 98% cross-channel match accuracy, with zero orphaned sessions.

The same memory layer now feeds the rest of the stack: a LangGraph orchestrator that answers in under five seconds, and retrieval that returns images as well as text.

Multi-Agent Orchestration

Orchestration Under Five Seconds

A LangGraph multi-agent system with asynchronous execution, smart caching and lean inter-agent message passing keeps round trips under 5 seconds. Model Context Protocol (MCP) carries context between agents and invokes in-house and external tools on demand.

LangGraph · MCP · Async
Retrieval

Pictures Now Answer Questions Too

An ingestion pipeline pulls images out of PDFs, reads the headings and text around each one, writes an LLM caption and indexes it in Pinecone with the image URL as metadata. The agent can now return the right text and the right image in one reply, with no upload from the user.

Pinecone · Multimodal · RAG
Automotive

A Bot That Listens To Your Engine

A proof of concept identifies the driver by phone number, pulls their vehicle data, and diagnoses engine faults from an uploaded audio clip with audio-classification models. It takes text, image or audio, and hands unresolved cases straight to service-centre booking.

Audio ML · Multimodal
Observability

Every API Call, On The Record

Analytics

“Ask-AI” Answers In One Sentence

An AI That Reads Your Medical Claim Before A Human Does

The AI-Powered OPD Claim Adjudication Platform pairs insurance rules with LLM document analysis to decide outpatient claims.

Prescriptions and invoices go in; structured claim data comes out, extracted by a multimodal Gemini pipeline. A Pinecone-backed RAG layer grounds each decision in policy documents, medical guidelines and historical claims.

Claims are routed by confidence: clear cases pass, suspicious ones hit fraud detection, and anything uncertain lands in a manual-review queue, with every step written to an audit log.
